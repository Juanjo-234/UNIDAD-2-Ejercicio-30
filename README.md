Resolución del ejercicio N°30 de la unidad 2 de programación 2.
Este programa simula una plataforma de streaming y gestión de contenidos multimedia capaz de reproducir películas, episodios de series y transmisiones en vivo de manera polimórfica, aplicando validaciones de disponibilidad y estado en tiempo real.

Clases Utilizadas
ContenidoDigital (Clase Abstracta): Define los atributos comunes como el título y la duración en minutos, junto con el método abstracto de reproducción.
Pelicula: Extiende la clase abstracta añadiendo atributos específicos de cine y simulando la proyección de largometrajes.
EpisodioSerie: Extiende la clase abstracta incorporando información de temporada y número de episodio.
TransmisionEnVivo: Extiende la clase abstracta añadiendo un control de estado en tiempo real para verificar si la señal se encuentra activa
